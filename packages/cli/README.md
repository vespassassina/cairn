# @cairn/cli

The `cairn` command: a thin HTTP client for [Cairn](https://github.com/vespassassina/cairn), a self-hosted wiki and table store where Claude and other agents are the primary client.

```
npm install -g @cairn/cli
cairn --help
```

Standalone executables (no Node required) are also attached to each release. Full install and usage instructions, including how to point `cairn` at your server and teach a coding agent to use it, are in [docs/CLI.md](https://github.com/vespassassina/cairn/blob/main/docs/CLI.md).
