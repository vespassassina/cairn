# ADR-019: Installation is written for an agent to follow, with the person at the checkpoints

Status: accepted, extended by ADR-031 (an agent guide to running Cairn, and a test that keeps both in step with the code)
Date: 2026-09-12

## Context

The owner expects most people to install and deploy Cairn by cloning the repository and asking their coding agent to do it. That changes who reads the install documentation first: an agent, which is good at running commands and bad at knowing what the person wants, and which must never handle their credentials carelessly.

## Decision

1. **`docs/AGENT-INSTALL.md` is the agent's script.** It says what to ask, in what order, what to run, how to check each step worked, and what to hand back.
2. **The agent asks where before doing anything:** this machine, or Azure. AWS is named as not available yet, rather than improvised.
3. **Credentials stay with the person.** The agent tells them exactly where to click and what to paste into the terminal. It never asks for a password or a secret in the chat, never echoes one back, never writes one into a tracked file, and uses the script's private settings file for anything it must keep. Signing in to Azure (`az login`) and creating the OAuth app are the person's steps.
4. **Every step ends with a check,** and the handoff ends with the checks that matter: the health endpoint, the console, Claude connected, and a first write that shows up in the console.
5. **The repository points agents at it.** CLAUDE.md starts with a short section for agents asked to install or deploy, and `AGENTS.md` at the root does the same for Codex, Cursor and others.
6. **The human guides stay complete.** `docs/LOCAL.md`, `docs/CLI.md` and `docs/DEPLOY-AZURE.md` are written for a person. The agent guide links to them for detail and never contradicts them.

## Consequences

1. Two audiences to keep aligned. A change to an install step updates both the human guide and the agent guide in the same commit.
2. The agent guide is a place where a mistake costs the person money or exposes a secret, so it gets the same review as code.
3. Whether agents actually follow it well is only known by trying. The first agent-run install, local and on Azure, gets an entry in `docs/LESSONS.md` either way.
