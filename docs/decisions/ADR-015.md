# ADR-015: Source-available, free for non-commercial use, under PolyForm Noncommercial 1.0.0

Status: accepted
Date: 2026-09-12
Answers: PRD Q4

## Context

Cairn is published at https://github.com/vespassassina/cairn. A public repository without a licence is "all rights reserved": the code can be read but not legally used, changed or shared.

The owner's requirement: anyone may use, change and do whatever they like with Cairn, but not for profit.

Licences considered:

1. **MIT or Apache-2.0.** Permissive, commercial use included. Does not meet the requirement.
2. **AGPL-3.0.** Chosen first. It stops a closed hosted service built on Cairn, but allows commercial use, including companies running it for themselves or selling a service that publishes its changes. Replaced before the first push, so it was never published.
3. **Creative Commons BY-NC 4.0.** Non-commercial, but written for creative works. Creative Commons itself advises against using its licences for software, and it has no patent terms.
4. **PolyForm Noncommercial 1.0.0.** Written by lawyers for software, specifically to allow any non-commercial use and nothing else without permission. Includes a patent licence and a defined list of non-commercial users.

No licence that restricts commercial use is "open source" as the Open Source Initiative defines it, because that definition forbids restricting how or by whom software is used. Such licences are called source-available.

## Decision

1. Cairn is licensed under the PolyForm Noncommercial License 1.0.0. `LICENSE` holds the published text, preceded by the line `Required Notice: Copyright (c) 2026 Diego Trinciarelli (https://github.com/vespassassina/cairn)`, which the licence requires anyone sharing a copy to pass on.
2. Every package declares `"license": "PolyForm-Noncommercial-1.0.0"`, the SPDX identifier.
3. Permitted without asking: personal use, research, experiment, study, hobby projects, and use by charities, educational institutions, public research, safety and health bodies, environmental organisations and government institutions. Changing Cairn and sharing it are permitted for those purposes too.
4. Commercial use needs a separate licence from the owner.
5. Cairn is described as **source-available, free for non-commercial use**, never as open source.
6. Dependencies must allow this. Today they are all MIT or similarly permissive (Hono, the MCP SDK, zod, markdown-it), which allows it.
7. The AGPL text was never published. A licence grant cannot be withdrawn, so the unpushed commit that held it was changed rather than followed by a new one.

## Consequences

1. Individuals, hobbyists, researchers, schools, charities and public bodies can use and change Cairn freely.
2. Companies cannot use it, even internally, without asking. That will cost adoption, and is the point.
3. On Hacker News, "source-available" draws criticism when a project blurs it with open source. Saying it plainly is the mitigation (PRD risk R6).
4. Contributions: code from outside contributors is theirs unless they agree otherwise, so the owner could not grant a commercial licence covering it. Before accepting outside pull requests, decide on contributor terms, such as a contributor licence agreement.
5. The review console embeds the owner's artifactkit styles and script (ADR-009), so they are published under this licence as part of Cairn.
6. GitHub's licence detector may show "Other" instead of a licence name. The README states the licence in plain words.
7. Relicensing later, for example to AGPL for wider adoption, stays possible while the owner holds all the copyright.
