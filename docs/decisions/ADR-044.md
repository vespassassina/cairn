# ADR-044: The project's name is Cairn, with no dedicated domain

Status: accepted
Date: 2026-09-15
Relates to: PRD Q5, ADR-015

## Context

PRD Q5 asked for a final name, to be checked against GitHub, npm and domain availability, and left CLAUDE.md calling Cairn a "working name". In practice the name was never provisional: the GitHub repository (`vespassassina/cairn`), the npm package (`@vespassassina/cairncli`, after `@cairn/cli` and unscoped `cairncli` both failed to publish, `docs/LESSONS.md`), the container images (`ghcr.io/vespassassina/cairn`), and every doc, ADR and ADR title already use it. Changing the name now would mean renaming all four.

A DNS check on 2026-09-15 found the short, obvious domains already registered: `cairn.dev`, `cairn.app`, `cairn.io`, `getcairn.com` and `usecairn.com` all resolve to a real nameserver. `cairnwiki.com` had no NS record and looked free, but the owner chose not to buy it. This matches the `cairn` npm org and `cairn` GitHub org both already being held by someone unrelated, from the npm publishing saga (`docs/DIRECTIONS.md`, 2026-09-15).

## Decision

1. Cairn is the project's name. Not provisional, not a placeholder for something else once it ships.
2. No project domain is bought. GitHub (`https://github.com/vespassassina/cairn`) stays the project's home; its README and `docs/` are what a newcomer reads.
3. `CLAUDE.md`'s "Cairn (working name)" becomes "Cairn": the qualifier is dropped.

## Consequences

1. PRD Q5 is answered and closed; `docs/ROADMAP.md`'s "Name decided" item moves to done.
2. The name collides with an unrelated party on npm and GitHub org names, already worked around by scoping under `vespassassina` (`@vespassassina/cairncli`) rather than the bare `cairn`/`@cairn` names. Anyone searching npm or GitHub for a bare "cairn" package will not find this project by that name alone; the README and this repository are the canonical way in.
3. Buying a domain later, if the project ever wants a marketing site or a custom email, is still open and does not need reopening this decision: it is an addition, not a rename.
